# qqbot-sdk-core：小助手的魔力核心 🌸

QQ Bot SDK 的共享 Rust 实现，负责鉴权、HTTP API、WebSocket / Webhook、消息模型与日志。✨

## 选一扇入口门 🪄

- 🦀 Rust 用户：[qqbot-sdk-rs](https://crates.io/crates/qqbot-sdk-rs)。
- 🍡 Node.js 用户：[@lovely-02/qqbot-sdk-js 使用指南](https://github.com/Lovely-02/qqbot-sdk-rs/blob/main/docs/13-nodejs.md)。
- 📚 开发与排错：[完整开发手册](https://github.com/Lovely-02/qqbot-sdk-rs/blob/main/docs/DEVELOPMENT.md)。

核心、Rust 入口与 Node.js 绑定共用版本；发布时先发布 core，再发布依赖它的 Rust 入口。🍀
