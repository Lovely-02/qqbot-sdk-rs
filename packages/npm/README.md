# QQ Bot 的 Node.js 小助手 🍡

用 TypeScript / JavaScript 收发 QQ 消息、订阅事件、管理群聊与频道，底层由共享 Rust 核心驱动。🌸

## 安装与起步 🪄

包名为 `@lovely-02/qqbot-sdk-js`，发布到 GitHub Packages。先完成仓库认证，再安装：

```powershell
npm login --scope=@lovely-02 --registry=https://npm.pkg.github.com --auth-type=legacy
npm config set @lovely-02:registry https://npm.pkg.github.com
npm install @lovely-02/qqbot-sdk-js
```

登录所需权限、环境变量、完整 TypeScript 示例、事件主题、Webhook 和源码构建，都收在 [Node.js 开发指南](https://github.com/Lovely-02/qqbot-sdk-rs/blob/main/docs/13-nodejs.md) 里啦。📚
